# 生产接入检查清单

- [ ] 平台应用已获企业正式授权，回调验签和 IP 白名单已启用
- [ ] 平台字段已映射为标准订单契约，状态映射有自动化测试
- [ ] `eventId` 在平台重试时保持稳定，在业务事件变化时产生新版本
- [ ] `.env` 已替换为 Secret Manager，所有默认密钥已轮换
- [ ] API 位于 HTTPS 网关后，已配置限流、访问控制和请求体上限
- [ ] `PROTECT_READ_ENDPOINTS=true`，读取密钥与内部、复核、管理密钥彼此独立
- [ ] `ENABLE_API_DOCS=false`，HTTPS 环境启用 `N8N_SECURE_COOKIE=true`
- [ ] PostgreSQL 使用托管/高可用实例，备份与恢复演练通过
- [ ] Outbox `RETRY/DEAD`、接口 4xx/5xx、数据库连接池已有监控告警
- [ ] 飞书应用遵循最小权限，表格和群机器人有明确负责人
- [ ] `NOTIFY_SEVERITIES`、日报和死信告警策略已由业务负责人确认，测试群与业务群已隔离
- [ ] PII 已按企业规范脱敏、加密并设置保留期限
- [ ] 自动退款、取消、冻结等高风险动作已接企业审批，不由本项目直接执行
- [ ] 规则阈值由业务负责人确认，变更有审计和回滚方案
- [ ] 已完成压测、故障注入、重复回调、乱序事件和灾备演练
- [ ] 已验证多人复核版本冲突、订单恢复自动闭环和异常复发重新打开
